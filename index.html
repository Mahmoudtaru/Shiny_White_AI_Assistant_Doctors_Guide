عدّل جزء واحد
  1. ارفع أفضل صورة متاحة للمريض: Face / Smile / Intraoral، ومعاها الأشعة أو الـClinical Notes لو ليهم علاقة.
  2. حدد نوع المخرج: After only، Before / After، خطوات علاج، أو Poster.
  3. اكتب الـCorrection أو الخطة المؤكدة: مثل veneers, crown preparation, implant-supported restoration.
  4. لو فيه شكل متخصص في دماغك، ارفع Reference Image وقل له يستخدمها للأسلوب أو الخطوة فقط، مش هوية المريض.
  5. لو النتيجة فيها مشكلة، سمّي المشكلة بدل «مش حلوة»: اللون، الطول، الـFramework، الملامح، أو ترتيب الخطوات.
قاعدة تقلل الأخطاءطلب واحد واضح في كل مرة أفضل من إنك تجمع تحليل أشعة + اختيار باقة + After + بوستر في رسالة واحدة.

05Quick Start

صورتك المطلوبة في Prompt واحد

ارفع صور الحالة، ثم اختار: After فقط أو مقارنة Before / After.

قبل النسخ: بدّل أي جزء بين [ ] بتفاصيل الحالة الفعلية.

After Image فقطلما تكون عايز النتيجة من غير بوستر أو كلام.

Using the uploaded patient images, create a photorealistic After-only dental treatment simulation. Preserve the exact same patient identity, face, lips, expression, head angle, lighting, and background. Modify only the dental structures required for: [TREATMENT OR CORRECTION]. Keep the result natural, conservative, and medically plausible. Do not add text, logo, hotline, branches, or poster elements.

Before / After فقطمقارنة نظيفة، من غير عناصر تسويقية.

Create a clean Before/After comparison using the uploaded original patient image as Before. In After, preserve the exact same patient identity, angle, crop, pose, expression, lighting, and background. Apply only this dental correction: [CORRECTION]. Do not beautify the face or modify non-dental features. Do not turn the result into a poster.

06مش عارف تبدأ؟

خلي المساعد يساعدك تختار وتكتب

الصفحة دي مفيدة لو الحالة واضحة عندك، لكن مش عارف أنسب مخرج أو صياغة الأمر.

مراجعة الحالة ثم اقتراح المخرجلما تكون عارف المشكلة، لكن مش عارف تطلب إيه بالضبط.

Review the uploaded patient images and radiographs for visual communication only. Summarize the clearly visible dental concerns without giving a definitive diagnosis. Then suggest the most useful output for this case: After-only simulation, Before/After comparison, treatment-steps visual, or patient poster. Ask me no more than one essential question.

خليه يكتبلك Prompt الحالةأنت اشرح الحالة بالعربي وهو يصيغ الأمر بالإنجليزي وينفذه.

Help me write the best prompt for this dental case. I will provide the patient images, current condition, intended treatment, desired output, and any reference image. Ask no more than one essential question, then write a concise English prompt and execute it.

The main problem is: [PATIENT IDENTITY / TOOTH SHAPE / SHADE / SIZE / GINGIVA / BITE / PREPARATION / FRAMEWORK / LAYOUT]. Correct only this issue and preserve everything else exactly as it is. Restore the original patient identity before making any cosmetic improvement.

التعديل باستخدام Referenceاستخدم المرجع للشكل، مش لنسخ المريض.

16Important Notes

8 ملاحظات قبل ما تبدأ

صورة واضحة واحدة أفضل من خمس صور ضعيفة أو متعارضة.
قول له After فقط لو لا تريد بوستر، أو Before/After فقط لو تريد مقارنة نظيفة.
لـPreparation أو Framework متخصص، ارفع Reference من حالاتنا.
لا تطلب منه اختراع Implant position أو Material غير موجود في الخطة.
لو عايز اللوجو الرسمي داخل التصميم، ارفعه في نفس الشات. غير كده يكتب SHINY WHITE نصيًا.
كل شات جديد: ارفع صور الحالة والـReferences المرتبطة بها مرة أخرى.
لو حصل Image generation failed، أعد إرسال طلب واحد مركز بدل جمع مهام كثيرة.
راجع الكتابة العربية والأرقام قبل إرسال أي Poster للمريض.
